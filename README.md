# Key Viewer

Geometry Dash 2.2081 · Geode 5.9.0 · v1.0.2

## 한국어

일시정지 메뉴에서 **키 뷰어**를 엽니다. 편집기 오른쪽 위에서 **라이트 모드**와 **다크 모드**를 전환할 수 있습니다. 마우스 휠로 설정 목록을 스크롤하거나, 오른쪽 가장자리를 끌어 내리세요.

- 캔버스의 키 또는 통계 박스를 클릭해 선택합니다. 해당 박스를 끌어 이동하고 선택 테두리의 손잡이로 크기를 조절합니다.
- 키 이름과 입력 매핑은 **키** 탭에서 편집합니다. 숫자 칸 위에서 마우스 휠을 돌려 값을 조절합니다. 터치 환경에서는 칸의 왼쪽과 오른쪽을 눌러 값을 낮추거나 높입니다.
- **노트 → 그라데이션 편집**을 열어 막대 왼쪽의 아래쪽 색과 오른쪽의 사라지는 끝 색을 고릅니다. 색상 선택 영역, 색상 띠, 투명도 띠로 각 끝을 조절하고 **색 적용**을 누르세요.
- **통계** 탭에서 KPS, 합계, 최고 KPS 박스를 각각 꾸밉니다. 기본값은 KPS와 합계의 가로 배치입니다. 위치를 드래그하면 직접 배치로 전환됩니다.
- **프리셋** 탭에서 오로라 민트, 오션 블루, 펄스 바이올렛, 선셋 코랄, 레드 네온, 실버 미스트를 선택할 수 있습니다. 저장하거나 적용하는 대상은 선택한 키 하나입니다.
- **배치** 모드에서 실제 레벨을 배경으로 위치를 조절할 수 있습니다.

## English

Open **Key Viewer** from the pause menu. Use the title-bar button to switch between light and dark. Select a key or statistics tile on the canvas to move or resize it. Hover over a numeric field and scroll to adjust it. On touch screens, tap the left or right half of the field. In **Note → Edit gradient**, select either stop to adjust its color and opacity.

## Build

With the Geode SDK and CLI configured, run `geode build` in this directory. GitHub Actions produces separate platform builds.
